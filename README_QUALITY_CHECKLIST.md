# README Quality Checklist — CivicShield

## Beginner clarity
- [ ] First paragraph says who this helps and what it does in plain language.
- [ ] A concrete example explains the normal user journey.
- [ ] Acronyms and specialist words are explained on first use.
- [ ] A beginner can follow setup commands and recognise expected output.

## Research and engineering depth
- [ ] Architecture, inputs, outputs and main components are described.
- [ ] Dataset and source provenance are documented.
- [ ] Assumptions, heuristics, simulation and sample data are labelled.
- [ ] Tests, benchmarks and reproducibility instructions are linked.
- [ ] Limitations and unsupported claims are explicit.

## Contribution quality
- [ ] CONTRIBUTING.md and FEATURE_UPGRADE_PLAN.md are linked.
- [ ] Activity log and company-fit page are linked.
- [ ] Each roadmap task has an owner-ready outcome and acceptance criteria.
- [ ] Public claims match the code on the default branch.
